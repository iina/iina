# App screenshots

These are actual iPad simulator captures from development on 2026-10-09 and 2026-10-10. They show the implemented interface, using synthetic video/audio and a test playlist. They are not mockups or performance measurements.

| Screenshot | What it shows |
| --- | --- |
| [Video settings](video-settings.png) | Track/codec information, aspect ratio, crop, rotation, speed, and video adjustments |
| [Playback speed](playback-speed.png) | The bottom speed picker, including 0.5×, 2×, 4×, and 8× |
| [Controls and layout](controls-layout.png) | Touch gestures, seek interval, hold speed, docked controls/sidebar, and seek-preview options |
| [Music mini-player](music-mini-player.png) | The audio-only interface with synthesized test music metadata |
| [Saved playlists](saved-playlists.png) | A playlist library containing an intentionally named UI test playlist |
| [Frame capture](frame-capture.png) | A clean test frame ready to save or share |

The video is intentionally low-resolution test media; visible color bars/pixels do not measure the player's output quality. See [fixture provenance](../Tests/Fixtures/README.md). Hardware decoding availability differs between a simulator and a physical iPad; a simulator warning is not a physical-device capability claim. Layout also depends on screen size, orientation, and selected preferences.

Only these reviewed copies are published. The original working screenshots and internal verification reports remain ignored. The copies retain their original pixels and were checked for personal content and embedded metadata before publication. They contain no personal media, account information, private file/share paths, or device identifiers.
