# Library Changes for 1.5.0

IINA, like many [open source](https://en.wikipedia.org/wiki/Open_source) applications, is built on top of code from other open source projects. For most of the other projects that IINA is dependent upon IINA builds [dynamic libraries](https://developer.apple.com/library/archive/documentation/DeveloperTools/Conceptual/DynamicLibraries/100-Articles/OverviewOfDynamicLibraries.html) (`.dylib` files) from the source code of these projects. To see these libraries right click on `IINA.app` in [Finder](https://support.apple.com/guide/mac-help/organize-your-files-in-the-finder-mchlp2605/mac) and click on `Show Package Contents`. Finder will then show the directory `IINA.app/Contents`. Double click on the `Contents` directory. Finder will now show the directories and files that makeup `IINA.app`. Double click on the `Frameworks` directory. Finder will show a large number of `.dylib` files. This document provides a high level description of the changes to the set of these libraries for IINA 1.5.0.

The table in the section below compares the set of libraries in IINA 1.4.4 to the set of libraries in IINA 1.5.0. This table describes the values shown in the big table below that illustrates the differences:

| Column | Description |
| --- | --- |
| Library in 1.4.4 | Filename of the library in IINA 1.4.4 |
| Version | Library version in IINA 1.4.4 |
| Library in 1.5.0 | Filename of the library in IINA 1.5.0 |

| Homepage | The library's homepage |
