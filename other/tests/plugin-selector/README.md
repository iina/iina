# Plugin selector regression checks

Run `bash other/tests/plugin-selector/run.sh` on macOS. The harness compiles the full production plugin controller, scroll control, navigation and constraint helpers. Plugin instances, the parent sidebar controller and placeholder UI helpers are fixtures; native AppKit controls and view installation are real.

Checks cover scrolling direction/order, gesture threshold and one-step behavior, momentum rejection, cyclic boundaries in both directions, first-plugin fallback, labels/content, plugin removal/reordering, active-first cyclic popup order and menu checkmarks. Persistence checks use an isolated UserDefaults domain: menu/scroll selection, independent open windows, delayed sidebar loading, reused and precreated players, unavailable/panel-less plugins, empty lists and passive fallback. Separate writer/reader processes verify restoration from disk by identifier, including a changed display name. The temporary domain is removed on exit; personal preferences are untouched. Native window checks also cover a still selector on sidebar opening, cylindrical perspective during an explicit roll, unchanged plugin content on opening, persistent foreground and hit testing, and full accessible titles. On macOS 26+, a separate noninteractive NSGlassEffectView replaces the segmented bezel that inflates on hover; the native cell still handles actions and accessibility. Zero-delta, below-threshold and cancelled swipes must leave the plugin, capsule, icon and resize queue unchanged.

Width and text are independent: a new title initially retains the previous capsule width, waits 120 ms, then resizes over 220 ms. Checks sample the delay and intermediate sizes, complete text behind the clipping mask, growth/shrink, rapid retargeting, repeated identical updates, fixed puzzle positions in both sidebar locations, available-width limits, detachment, Reduce Motion and disabled animations. The fixture supplies realistic Auto Layout behavior for plugin views, separators and the header host. Rendered title images are saved under `build/plugin-selector-tests`.

Popup activation and bidirectional scrolling were checked in the isolated Contact Lab with temporary local plugins. Frozen production animation poses were inspected through native macOS rendering to verify projection, clipping and direction. Physical trackpad feel and perceived timing remain manual acceptance.
