This suite extracts both production shortcut dispatchers, the shared mpv command parser/policy, the seven raw JavaScript methods and their lifecycle boundary, menu validation, saved-filter dispatch, and the complete native Crop/Delogo implementation. It attempts structural commands through modified shortcuts and raw plugin calls while preserving seek, pause, volume, frame steps, unrelated audio/subtitle commands, and nonreplacing playlist edits. It also checks empty mappings, post-editor access, visible menu restrictions, and idle/shutdown plugin access.

Run `bash other/tests/video-editing-command-routing/run.sh`. Optional environment variables select `VIDEO_EDITING_ROUTING_OUTPUT_DIR`, `VIDEO_EDITING_ROUTING_MODULE_CACHE`, and `VIDEO_EDITING_ROUTING_LIBMPV`. Supplying the built app's bundled library also exercises accepted commands against that engine with null video/audio outputs; it never loads a media file. Engine calls are recorded at the native API boundary. Without a library, that boundary uses controlled values.

Windows remain hidden with prohibited activation and disposable defaults. This is focused production-source integration, not full-app event routing, native PiP/fullscreen presentation, IPC/script-generated commands inside mpv, or arbitrary external plugin behavior.
